## Exact matcher extensions

These are reference-side semantic requirements. They do not prescribe a parser node layout or authorize a per-window graph builder. An unimplemented extension must fail, never be silently ignored.

1. **Main-event anchoring and atomic identity.** `events[].anchor` identifies the source action span, in addition to recursive producer anchors already present in selectors. All predicates for one event must concern the same matched event. A missing/wrong main action makes its descendant atoms fail; helper literal/load/alias events cannot earn those atoms. Ancestor aliases may only be traversed as provenance-preserving representations, not accepted by numerical equality. Anchors denote source coverage/identity, not necessarily an implementation's exact punctuation boundary.

2. **Method contract.** The existing `method_contract.definition_anchor` is augmented by `formal_inputs`, `required_return_roles`, `body_required`, `actual_binding_identity`, `body_semantics_required`, `output_must_depend_on_actuals`, and where relevant `source_parameters_required`. These check the actual callable definition/body and call mapping; a name/signature or claimed metadata string is insufficient. A return must be backed by actual body execution with the selected call's current inputs. Equivalent source-derived internal decompositions are allowed.

   A01 retains formal `offset` for the updated day count and adds explicit formal `head_day`. Its definition is2.3's sixty-cycle/outside-count slice. A02.05 uses formal **`month_offset`**, sourced recursively from A02.04's updated whole months after the carry. Its definition is2.15's complete suffix starting `以元月除積月` and ending `則星所見月也．`: Origin reduction, Rule reduction,12/13-month scan and天正 count. `appearance_month_ordinal` and `cyclical_day` are reference semantic return-role names, not mandated internal variable IDs. Source parameters元月/章月 are resolved in the definition; they are not fabricated task inputs. Do not call the old method and replace new state with its previous result.

3. **`source_epoch_frame` contract.** Checks same conjunction call identity and actual head binding, using the registered `C2017_ST_origin_month_day_frame_v1`. The Origin frame follows§193's 月元餘 definition. Preserve§195's competing Concordance-head description. The fixed143127 epoch cannot discriminate them; equal head values do not pass source-frame identity. The reference does not introduce a global Origin/Concordance alias.

4. **`source_parameter_role` and `current_state` contracts.** The former checks that interval13/15079 originates in the Jupiter declaration§27 and remains distinct from computed same-name quantities. The latter checks that the updated fractional remainder comes from A02.03's remainder port, belongs to the same updated appearance state as the method call, and is not reset. This does not require the month-order method to take an unused fractional formal input.

5. **`source_reuse` contract.** The right operand of A04.01's real `add` must reuse the **increment role** of2.30's `當加大餘三十九`, not its result or the earlier initialized39 literal. The reference still uses ordinary literal/source selectors for the39 token, but the separate contract establishes the operation/increment link. Merely finding a39 or adding a helper load cannot satisfy it. The main action must consume the reused increment.

6. **`query_base` contract.** Checks the matched `add`'s left operand against a real source-derived initial-state component. T0's lawful root `query_initial_rule_ordinal=0` selects elapsed zero Rules from the Concordance Head; `epoch_elapsed_years` and2.1 derive the head, and§3–4 supplies its midnight coincidence frame. Both query instances share that initial state while reading their own whole/fractional components. No computed head or remainder is supplied. `component_unit`/`fraction_denominator` check day versus day-fraction numerator at81, not labels alone. The event cannot read the other query's result.

7. **`query_isolation` contract.** Pairs A04.01/.02 for Section and A04.03/.04 for Circuits Culmination, with independent calls/exports from the same immutable initial state and carry at81. Check reversed query order through actual execution evidence. A graph field claiming order independence is insufficient. Query names here are reference roles attached to source spans, not required domain-classifier keys.

## Accounting and gates

Every `fixed_atoms[].predicate_path` is a stable pointer into its policy. Atomic predicates are main-kind/source, individual recursive producer kind/port/source, terminal input/literal/parameter properties, individual event attributes, and individual method/contract requirements. A composite requirement succeeds only when all listed content is verified; absent evidence fails. The listed369 denominator is fixed regardless of output size. Shared contract atoms are counted once under their first attached obligation; every attached obligation still requires the contract to pass.

A relation score is not a complete-chain score. All four windows still require actual exports, execution without relevant unresolved facts, and correct essential dependencies. Contracts containing execution or reverse-order requirements need real executor evidence. Never use a diagnostic-list assertion as a substitute. The A04 task is explicitly conditional; the unmodified old packet remains underdetermined.

The existing22 Chinese/scholarly obligations and provenance are preserved. Only the old unsupported A02.05 policy and insufficient A04 literal/receiver proxies are replaced; other policies are strengthened by source/call requirements without dropping their original relationships. Original numeric parameter values remain source constants, not expected answers.
