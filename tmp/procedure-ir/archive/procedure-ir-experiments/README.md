# Procedure IR Generated Artifact Archive

This directory holds generated artifacts from exploratory Procedure IR work that is not part of the current active Cullen chunk stabilization surface.

- Phase 2A pilot artifacts.
- Sifen corpus profile, template discovery, clause alignment, candidate evidence audit, and Proc. 3.5 trials.
- Legacy source-side / refined source-Cullen alignment outputs.
- One-off git hygiene and architecture snapshot reports.

Current active `tmp/procedure-ir` should stay focused on:
- Cullen pages/chunks/search index.
- Cullen oracle, claims, claimbank, termbank, procedurebank.
- Cullen procedure inventory/anchors and their audits.
- Cullen-led source reconstruction and Phase 1 baseline.
- Current chunk structure audit files.

Archived files are retained for reference only. Do not use them as gold, final evidence, or active pipeline inputs unless explicitly promoted back.
