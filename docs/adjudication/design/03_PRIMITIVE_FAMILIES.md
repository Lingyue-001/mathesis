# 03 有限扩充：五个语义能力包＋一个表达适配包

这里的P1–P5是开发范围分组，并不要求每组只对应一个新opcode。优先复用现有add/subtract/fraction/convert/method等实现。source→syntax、syntax→semantic、semantic→execution、evaluation四种支持状态分开登记。

**有限的是操作类型目录；任意新原文都能低成本填入的保证尚未成立。** 此轮只补已出现缺口中反复可复用的几种能力，不宣称解决全部43窗。

## S1 显式受事和省略恢复：表达适配，不另造数学运算
线索：3.19 `以增夜半日所在度分`；4.32裸`日餘…，小分…`的更新语境。
作用：研究者选择Update(receiver, delta, mode)，每个槽可绑定source span或已有量端口。其结果使用已有Add/Subtract，不为每句创造opcode。
不得把增/益/加作无条件全文替换；先确定当前表达的受事、方向、操作数和适用scope。判断来自人时保留manual_construction标记。

## P1 条件、范围、分类与受控分支
来源线索：3.11 `無分為滅`；3.28带上下界的余分；3.32 `不滿二十者`。
- Predicate：eq/ne/lt/le/gt/ge；区间由两个Predicate及And表示，端点闭开显式。
- If：condition、then_body、else_body、作用域；未执行分支仍保留在定义与图中。
- Classify：把既有事件附以源文类别标签，原标签不改成现代同义词。
- 谓词对象、then/else对应、边界等号都是可审定槽，不由最终数值反推。
- 若分支都产生一个后续量，用具名合流输出并保存每条来源，不混用未执行分支状态。
验收：零分与非零分、阈值两侧、上下界、反转分支、同数值错predicate必须分别检查。

## P2 有理数量、符号更新、进位/借位
来源线索：4.32的嵌套分数增量；4.36的余不足、退日；现有C2商余进位。
- 精确有理数是执行格式；源文分子、分母、整部及未约分形式继续保留。
- Update/NormalizeParts：quantity、增减项、分母/进制、进/退位目标、条件。
- 每个组分有单位、尺度、producer和时间/位置参照。跨维度必须有具来源的rate。
- 一组更新按原文顺序执行，或按已声明的同时更新规则读取旧状态；两者不得混用。
- 负数可执行，不等于自动解读“强弱”“阴阳”等历史符号。该映射必须单独有profile及来源。
验收：相同数值不同尺度、不同分母相加、整部借一、分数边界、保留两级余分；删rate后应阻止转换。

## P3 一般表格读取
来源线索：现有四分纪蔀表；4.55静态表应能成为背景数据而无须伪造执行过程。
- table_id、table_hash、row_selector、column/field_selector、索引基准、输出类型与行列出处。
- 输入可以是已算出的索引；输出可以是年名、日名、数值或量结构。
- 不继续固定返回head_day/head_year；旧历元查表作为既有适配保留。
- 缺行、缺列、重复key、index越界产生明确问题；禁止补入现代替代表格来自动凑齐。
验收：同数值不同列、行号0/1基准、删除表项、全表hash改变、参数与实际查得值来源区分。

## P4 有序不等长区间遍历
来源线索：3.23 `[以]宿次除之`。
- 输入位置量、区间表、顺序、起点、方向、循环总长/有限终点、边界规则。
- 输出区间身份、区间内余量、经过的区间与消去轨迹。
- 不能将“宿次”当一个标量除数。也不能默认一周360度、各宿等宽。
- 是否跨斗扣分、区间边界归属等属于有来源的模型配置；未给足时保留未完成。
- source procedure的逐项消去结构和程序优化后的前缀和查找可分视图，证据层不删除原组织。
验收：不等宽表、恰到边界、跨周、反向、分数宽度、表总长不一致、输入时间量误用为角位置。

## P5 有限的表驱动/多状态递推
来源线索：4.28 `益轉相益，損轉相損`；4.40完成一序列后的更新。
- Fold/BoundedRepeat：初态map、已声明顺序的行/事件序列、step_body、计数与停止谓词、返回状态。
- step_body仅允许目录内节点；不执行自由Python、自然语言或用户lambda。
- 更新可涉及多个具名状态；先/后测、逐步/同时更新、符号方向及跨序列继承显式。
- 缺初态、表项、界限，或出现无界递归时阻止完整执行。人工可选择现有规则，不能用最终答案补初态。
- 本轮不开发任意插值、任意高阶数值模型。遇到需要的新模型登记extension_required。
验收：交换表行、反转符号、改变body但不改显示文本、迭代上限、跨次污染、最后一行是否执行。
