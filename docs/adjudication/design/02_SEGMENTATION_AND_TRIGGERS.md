# 02 人工边界：分层、可自由选择位置、受结构约束

## 1. 自由切分的确切含义
允许研究者在当前校读版本的任意合法字符边界选择位置，切开或合并机器没有提出的片段。原文保持只读，操作产生stand-off分析记录。

边界选择可以自由，节点类型和连接规则受版本化目录约束。研究者不用写JSON或代码。无法使用已有类型表达时登记扩展需求。

禁止用“自由切分”插入原文不存在的字、删除难句、偷改校读。需要校勘时另开reading版本，显示旧/新字和来源，旧判断失效而非自动迁移。

## 2. 四层对象
|层|人工可做什么|必须保留的限制|
|---|---|---|
|L0 来源与校读|查看版本、选择已声明校读|原件不可变；offset对应reading，另有到原件映射|
|L1 过程/查询/阶段|圈出或合并过程；指定子过程、查询的父级和基态；阶段可跨数句|物理/编辑段落与分析边界分别保存；跨文档关系采用引用；不把所有“求”强制变顶层|
|L2 构式与控制|划分完整操作表达；把多项运算组成Sequence；为条件选择条件式、then/else和停止区域|一句可多操作，一操作也可多跨度；不可要求一小句恰好一个事件|
|L3 词项/角色/引用|标记数词、完整术语、代词、动作线索；指定量来源、单位、分母、接收对象|同一source span可以支撑多个语义节点；重叠须显式，不能用覆盖字数冒充语义正确|

L1中的阶段是比较和解释的分组，可作为带来源的叠加层；不要求每个阶段都必须成为独立可调用函数。L2的控制边界、L3的量引用最终进入程序图。
同一个表达可能同时承担条件与操作含义，应保存共享证据引用；调用前文、后置声明和不连续受事通过关系表达，不能为了连续分段改变文本顺序。

## 3. 一个例子
`以見月法乘其小餘并之`可以圈出乘法短语与末尾`并之`，前者生成Multiply，后者生成对先前累计量的Add。乘法中的`其小餘`仍需绑定正确的上游余数。
仅完成切分不能宣布完成这条计算：若先前累计量或`小餘`来源未定，界面继续显示必要的绑定问题。
例句用于说明标注操作；实际程序须读取完整上下文，不能把本段设计文字当作原始史料解释。

## 4. 坐标与修改规则
- 地址：doc_id、reading_id、SHA-256、Unicode code point的半开区间[start,end)、quote。
- 浏览器DOM使用UTF-16时必须转换到code point；测试补充平面字、组合符、CRLF和重复原句。
- L1父子必须有有效层级；交叉关系使用引用边，不能形成相互包含循环。
- 合并/拆分后重新词法化受影响区域，不沿用旧节点序号猜绑定。
- 判为非计算说明必须有人工理由和跨度，保留在覆盖台账；必要输出依赖该跨度时拒绝用此跳过。
- 系统可以保留多个切分方案。不同方案作为不同分析分支，不把相互冲突的边一起执行。

## 5. 何时进入人工队列
|触发|处理|
|---|---|
|没有合法候选、UnsupportedConstruction、Hole、未消费动作|允许重切、用已有类型构造；若语义类型也无则扩展请求|
|多个合法解析/多个producer/多个分母|展示候选及依据；选择、拒绝或保留分支|
|单位、率、时间原点、作用域、端口发生冲突|定位最早冲突；纠正上游判断，不能关闭检查强行执行|
|缺原文、根输入、表、方法体或解释profile|补来源、登记外部依赖或保留未完成|
|同一表达对应条件范围、进位等号、前/后测次序的多解释|明确选择已登记解释或创建有来源的分析分支|
|机器仅给唯一候选且检查无冲突|可自动作为暂定结构，但首次真实目标须整段确认；允许研究者主动纠错|
|已确认上游改变、reading/ontology/profile变化|受影响决策置needs_revalidation，重新排队|

唯一候选和类型一致只能排除一部分错误，不能证明历史理解正确。当前规则没有经过校准的概率置信度，UI不得显示虚构的“95%可信”。

## 6. 队列顺序与成本
先解决reading和背景、L1目标/基态，再解决L2结构和L3绑定，最后显示跨过程与执行问题。一次上游修正可消掉多条下游缺口，UI应合并说明其影响。
所有自动区段都可展开检查；不要只向研究者展示机器承认不知道的部分。
